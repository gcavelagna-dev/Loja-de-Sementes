# *Sistema Para Gestão de Sementes*
*Um exercício de **gerenciamento de sementes** com proposta de integrar a quantidade de sementes ou vender/comprar sementes para fins de aprendizagem de Java OOP.*

### *Desenvolvimento:*
No começo, queria desenvolver algo básico somente para mais um exercício de POO, onde eu estava aprendendo voltado para conceitos iniciantes, mas avançados.
Sinceramente, não sabia o que deveria fazer literalmente como este projeto, pois ele era para passar o tempo e praticar com algo que estou gostando no momento, que é 
jogar *Stardew Valey*.

Desenvolvendo este projeto, estava lembrando conceito de java **"Escreva uma vez, execute em qualquer lugar"**, eu queria desenvolver algo onde eu escrevesse o código uma vez e ele rodasse em todas as classes sem a necessidade de repetições.

### Problemas encontrados:
Com essa ideia de poder escrever uma vez e passar para todas as classes, veio a ideia de **herança** porque querendo ou não, faz muito mais lógica de escrever somente uma vez e as classes filhas entender todas as regras.

Consegui fazer os primeiros testes com várias repetições, não sabia nem por onde dava para melhorar, até começar a fazer a classe "**Inventario**", onde precisava utilizar uma lógica onde guarde todos os tipos de frutas, vegetais, etc...

#### Como Resolvi o sistema para guardar as sementes?
Nunca utilizei HashMap<>(), mas aprendi parte devido à necessidade de utilizar, o que foi ideal para o problema, onde guardava os Objetos, mas logo veio uma dúvida, como faria para guardar cada tipo? E isso deu a ideia do **Polimorfismo**, onde utilizei a **superClasse** como tipo e instanciei o objeto como as categorias.

#### Exemplos:

*Semente abobora = new Abobora();*

*Semente batata = new Batata();*

*Semente melao = new Melao();*
